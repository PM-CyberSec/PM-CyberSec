![Python](https://img.shields.io/badge/Python-001F4D?style=flat-square&logo=python&logoColor=white) ![FastAPI](https://img.shields.io/badge/FastAPI-0052CC?style=flat-square&logo=fastapi) ![Wazuh](https://img.shields.io/badge/Wazuh-00FFCC?style=flat-square&logoColor=001F4D) ![Docker](https://img.shields.io/badge/Docker-001F4D?style=flat-square&logo=docker&logoColor=white)

Containerized SOAR ecosystem for SIEM, EDR, and NDR telemetry correlation and automated response.

* Architected a fully containerized SOAR platform with Docker, integrating Wazuh (SIEM), TheHive (case management), Cortex (enrichment), and Velociraptor (EDR) for centralized telemetry across distributed environments
* Managed modular service orchestration with Docker to ensure consistent deployment, isolation, and scalability
* Engineered IR playbooks via REST APIs for automated actions including endpoint isolation and IP blacklisting
* Integrated an AI Decision Engine to trigger playbooks based on real-time threat detection patterns
* Implemented LLM-assisted log classification with confidence scoring to reduce alert fatigue and improve triage
* Developed ML-based severity prediction to prioritize high-risk alerts

#### 🧠 Network Forensics — ML-Based C2 Detection from PCAP | [View Project](https://github.com/PM-CyberSec/SUTech-courses-labs/tree/DigitalForensics)
![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-001F4D?style=flat-square&logo=scikit-learn&logoColor=white) ![Pandas](https://img.shields.io/badge/Pandas-0052CC?style=flat-square&logo=pandas) ![Suricata](https://img.shields.io/badge/Suricata-00FFCC?style=flat-square&logoColor=001F4D)

Machine learning pipeline for detecting command-and-control communication and data exfiltration in network traffic.

* Built an ML pipeline with Scikit-learn to detect anomalous traffic patterns indicative of C2 and exfiltration beyond signature-based IDS
* Engineered features based on flow duration and packet entropy to improve zero-day detection capability
* Integrated Arkime (Moloch) for full-packet capture indexing, metadata analysis, and breach reconstruction
* Validated detections across Zeek, Suricata, and Wireshark for multi-layer traffic analysis
